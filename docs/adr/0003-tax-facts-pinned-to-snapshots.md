# 稅務數字人工整理，但每一筆都釘在爬蟲抓下來的官方原文上

**Status**: accepted（2026-10-15）。已實作。

網站的稅務內容（指南、試算、WebMCP 工具）用到的每一個數字與規則 —— 免稅額、級距、
扣繳率、183 天、申報期間 —— 都寫在 `content/tax/facts.yaml`，每一筆附上
`evidence`：哪一份原文快照（`data/tax/snapshots/<id>.md`）、裡面的哪一句話。
爬蟲每週重抓官方頁面，抓完核對每一句引述還在不在；對不上的數字在網站上標「待複核」，
直到有人回頭改 facts.yaml。

## 為什麼這值得記下來

看程式的人會看到一個爬蟲專案裡有兩百多份政府網頁的文字快照，卻沒有任何程式從快照
「解析」出數字 —— 數字是人工寫在 YAML 裡的。直覺會問「既然都抓下來了，為什麼不自動解析」，
或者「為什麼不乾脆讓模型讀快照回答」。

## 考慮過但沒選的

- **從快照自動解析數字**（正規表達式撈「97,000 元」）—— 政府網頁的版面與措辭三不五時就改，
  撈錯不會報錯，只會安靜地把錯的數字放上網站。這正是 IMPLEMENTATION.md 第 12 節說的
  「下層壞掉會默默給錯的東西」。稅務數字錯一個，比整頁沒更新更糟。
- **讓模型讀快照即時回答** —— 同一個問題每次答得不一樣，而且答錯時沒有任何東西會亮紅燈。
  WebMCP 工具回傳的是固定的 facts 與它們的核對狀態，Claude 負責把它講成人話，不負責決定數字。
- **只放連結、不抓原文** —— 連結不會告訴你「這頁上個月改了」。快照 commit 進 repo，
  財政部改一個字，那週的 data commit 就是一段看得懂的 diff。

## 查到的事實（2026-10-15）

- 起點是使用者提供的整理文件（6 個政府來源、2 個民間來源、2 個工具），擴充後設定檔有 56 個起點、
  跟著連結展開成 230 多頁：財政部外僑專區（75 篇條目）、臺北國稅局中英文專區、行政院公報上的年度金額公告、
  財政部新聞稿、勞動部最低工資、法規資料庫（所得稅法、所得基本稅額條例、各類所得扣繳率標準、
  外國專業人才延攬及僱用法與其減免所得稅辦法）、財政部函釋、Talent Taiwan。
- **財政部外僑 FAQ 有 5 頁在官方網站上本身就是空的**（只有標題與更新日期）。爬蟲標成 `empty`，
  網站照實顯示，不拿別的頁面硬補。
- **特定專業人才租稅優惠只有臺北國稅局有完整頁面**，2025 年修法後條號從第 20 條改為第 22 條，
  而且就業金卡持有人在卡片有效期間受聘僱也適用。國稅局另一頁「中華民國來源所得」與
  Talent Taiwan 的 FAQ 仍是舊條號 —— 指南裡有提醒。
- **Talent Taiwan 是 SPA**，靜態抓只有空殼；前端自己打的內部 API 中英文都有（階梯第 2 層），
  而且那支 API 也有活動資料，順便成了一個新的活動來源（含報稅季前的稅務說明會）。
- 國稅局的中英對照手冊是 PDF，放在 `/download/` 底下，robots.txt 禁止 —— 只快照目錄頁、網站上連過去。
  國發會延攬法專區在 Cloudflare 挑戰頁後面，104 對誠實標示的爬蟲回空頁 —— 都不繞過，只列連結。
- Python 3.13 起預設開啟嚴格 X.509 檢查，政府憑證鏈缺 Subject Key Identifier 會被拒。
  解法是只拿掉那一個旗標、其他驗證照做（`base._GovCertAdapter`），不是 `verify=False`。

## 後果

- **新年度的金額要人來加。** 財政部每年 11 月底公告下一年度的免稅額與級距：在 facts.yaml 加那一年的
  facts（附公報引述）、在 `content/tax/params.yaml` 加一個年度。2026 年度的基本生活費在本 ADR 寫成時
  尚未公告，暫用 2025 年度金額並標 `provisional`，網站與工具都會說出來。
- **待複核不會讓 CI 紅燈。** 核對結果只影響網站上的標示與工具回傳的 `status`；離線測試只檢查結構
  （每一筆都有 evidence、來源存在）。否則對方改一個字，每週的活動抓取就被擋住。
- **引述要挑「數字所在的那一句」。** 引整段的話，旁邊改一個字也會誤報待複核。
- **被引用的頁要有固定 id。** 跟連結找到的子頁預設用路徑推導的 id；被 facts 引用的頁一律在設定檔的
  `names` 給名字。一頁不再被爬到時會被標 `stale`，引用它的數字自動降成「未核對」，不會一直掛著已核對。
- 試算的範圍刻意收窄：配偶有台灣所得的合併／分開計稅、列舉扣除的細項、海外稅額扣抵都不做，
  畫面與工具說明都寫明，並連到財政部的官方試算。
